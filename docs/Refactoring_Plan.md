# План рефакторинга

Цель: обычное изменение предмета, персонажа или интерфейса должно требовать
понимания небольшого числа связанных мест. Сохраняем компоненты и ресурсы,
но делаем их удобными для автора контента и разработчика.

## Порядок работы

- Завершаем небольшую задачу, проверяем затронутое поведение и делаем коммит.
- В коммит включаем только изменения текущей задачи.
- Отмечаем выполненные пункты и результаты проверок в этом файле.
- Изменение игровых правил отделяем от переноса существующего кода.
