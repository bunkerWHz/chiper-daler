# Настройка дропа с монстров

Дроп настраивается в Inspector сцены монстра. Скрипты менять не нужно.
Янтарные осколки выпадают отдельно и подбираются автоматически: [экономика](Amber_Economy.md).

Главный путь: **_Components → LootDropComponent → Loot Entries**.

## Добавить предмет в дроп

1. Откройте сцену нужного монстра из `game/enemy/monsters`, например
   `stone_maw/StoneMaw.tscn`, или свою [копию врага](Enemy_Copy.md).
2. Выберите `_Components/LootDropComponent`.
3. Раскройте **Loot Entries** — список возможного дропа.
4. Добавьте элемент массива (увеличьте **Size**) и в пустом элементе
   выберите **New LootEntry**. Нажмите на созданный ресурс, чтобы раскрыть поля.
5. В **Item** перетащите ресурс предмета `.tres` из `game/items`.
   Нужен сам предмет, а не его картинка `.png`.
6. Укажите количество и шанс по таблице ниже. Сохраните сцену.

| Поле | Что задаёт | Пример |
| --- | --- | --- |
| Item | Какой предмет выпадает | `game/items/ammunition/TrainingArrows.tres` |
| Minimum Quantity | Минимальное количество при успешном выпадении | `2` |
| Maximum Quantity | Максимальное количество при успешном выпадении | `5` |
| Drop Chance | Вероятность выпадения этой записи, от `0` до `1` | `0.5` = 50% |

Для точного количества задайте одинаковые Minimum и Maximum, например `1` и `1`.
Минимум должен быть не меньше `1`, максимум — не меньше минимума.
Для редкого предмета меняйте шанс, а не ставьте минимальное количество `0`.

Новые предметы создаются отдельно: [инструкция по предметам](../game/items/README.md).

## Пример таблицы дропа

Добавьте два отдельных LootEntry:

| Предмет | Minimum | Maximum | Drop Chance |
| --- | --- | --- | --- |
| TrainingArrows | 2 | 5 | 0.5 |
| TrainingSword | 1 | 1 | 0.1 |

При смерти монстра стрелы выпадут с шансом 50%,
меч — с шансом 10%. Количество стрел случайно выбирается от 2 до 5 включительно.

Каждая запись разыгрывается независимо: могут выпасть оба предмета.
Шансы не обязаны в сумме давать 100%. Это не выбор одного предмета из списка.
Если нужна именно такая механика, её текущая таблица не реализует.

Все выпавшие предметы помещаются в один мешок. Если ничего не выпало,
мешок не создаётся. Повторный сигнал смерти не создаёт второй дроп.

## Разный дроп у разных монстров

Общая сцена `features/loot/LootDropComponent.tscn` сейчас содержит
**пустую таблицу обычного дропа**. Изменение этой общей сцены затронет
монстров, которые используют её настройки без собственных переопределений.

Для индивидуального дропа редактируйте Loot Entries внутри сцены нужного монстра.
Создавайте для него **New LootEntry**. Если меняете уже существующую запись,
сначала откройте меню этого ресурса и выберите **Make Unique**.
Повторите для каждой записи, которую собираетесь менять.

Сам **ItemData** в поле Item можно оставить общим: несколько монстров могут
ронять один и тот же меч. Make Unique у LootEntry отделяет шанс и количество;
оно не означает, что свойства самого предмета стали независимыми.

Кнопка создания копии врага не гарантирует независимость Loot Entries:
для настройки дропа новой копии также создайте свои записи или сделайте их уникальными.

## Удалить предмет или полностью убрать дроп

- Чтобы убрать один предмет, удалите его элемент из Loot Entries.
- Чтобы монстр вообще не ронял лут, удалите его `LootDropComponent` из сцены.
  Пустой список у оставленного компонента считается ошибкой настройки.

## Мешок и подбор

**Loot Bag Scene** задаёт внешний объект дропа. Обычно оставляйте
`features/loot/LootBag.tscn`: эта сцена отвечает за картинку, падение и подбор,
а Loot Entries — за содержимое.

Размер мешка меняется в `LootBag.tscn` через **корень LootBag → Transform → Scale**:
X и Y должны быть одинаковыми. Спрайт оставляйте с масштабом `1, 1`.
Изменение общей сцены мешка влияет также на предметы, выбрасываемые из инвентаря.

Герой подбирает лут кнопкой **R**, когда находится рядом с коллизией мешка.
Дальность задаётся в сцене героя: **_Components → InteractionComponent →
Interaction Distance**, по умолчанию 48 мировых пикселей.
Масштаб мешка учитывается при поиске ближайшей точки взаимодействия.
Если инвентарь принимает только часть предметов, остаток остаётся в мешке.

## Проверить настройку

1. Для первого теста поставьте предмету Drop Chance `1.0` и количество `1–1`.
2. Разместите нужного монстра в тестовой сцене и убейте его.
3. Проверьте, что появился мешок, упал на землю и подбирается с земли кнопкой R.
4. Проверьте полученный предмет в инвентаре.
5. Верните желаемые шанс и количество, сохраните сцену.

Если дроп не появился, проверьте Item, Loot Bag Scene, диапазон количества
и наличие работающего HealthComponent у монстра. Посмотрите ошибки в Godot.
При шансе меньше 100% отсутствие дропа в отдельном убийстве нормально.

Постоянные флаконы, например текущие `HealthPotion` и `ManaPotion`,
не допускаются в дроп: LootEntry их отклоняет. Для проверки используйте
боеприпасы или экипировку.
