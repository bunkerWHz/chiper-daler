# Создать самостоятельного врага

1. Откройте `game/enemy/GroundDummy.tscn` для наземного врага или
   `game/enemy/FlyDummy.tscn` для летающего.
2. Выберите узел `EnemyAuthoringChecks` в дереве сцены.
3. В Inspector укажите `New Enemy Name`, например `ForestBat`.
4. Нажмите **Create independent copy**.
5. Откройте созданную сцену `game/enemy/monsters/forest_bat/ForestBat.tscn`.

Кнопка сохраняет текущую сборку сцены в новую папку. Масштаб корня новой копии
всегда сбрасывается в `1, 1`, даже если в оригинале он был изменён.
В папке будут сцена, собственные `SpriteFrames.tres` и
`AnimationLibrary.tres`. Конфигурации компонентов копируются внутрь новой
сцены. Общие компоненты остаются экземплярами своих сцен, а новая сцена врага
не наследуется от исходного врага. Исходные текстуры могут использоваться
повторно при копировании готового монстра.

У заготовок Dummy графика не назначена. При копировании автоматически создаются
пустые анимации `idle`, `move`, `airborne`, `attack`, `death`. Добавьте свои
кадры в SpriteFrames, настройте скорость, длительность клипов AnimationPlayer
и события удара. До заполнения предупреждения об отсутствующих кадрах ожидаемы;
пустую заготовку не размещайте в игровом уровне как готового врага.

Готовые монстры коллекции находятся отдельно:

- `game/enemy/monsters/stone_maw/StoneMaw.tscn` — наземный зубастик.
- `game/enemy/monsters/amber_wasp/AmberWasp.tscn` — летающее насекомое.

У каждого своя папка с кадрами и библиотекой анимаций. Для создания нового
монстра начинайте с GroundDummy или FlyDummy, для размещения на уровне выбирайте
заполненную сцену из коллекции.

Имя должно быть допустимым идентификатором без пробелов и разделителей пути.
Существующая папка никогда не перезаписывается. Открывать нужно саму сцену
врага: кнопка не создаёт копии из экземпляров, размещённых внутри уровня.

После копирования:

- Рисунок: `_Visual/AnimatedSprite2D` → Sprite Frames.
  Все исходные спрайты заранее подготавливайте смотрящими вправо.
  Для поворота влево игра использует flip_h; отдельной настройки направления нет.
- Общий размер: корень созданного монстра → Transform → Scale,
  одинаковые X и Y. Исходное значение новой копии: `1, 1`.
  Масштаб AnimatedSprite2D оставляйте `1, 1`, смещение задавайте его Position.
  Формы коллизий и зоны обнаружения задаются в локальных пикселях и растут
  вместе с корнем. Подгоните формы под свои кадры, затем задайте общий размер.
- События и длительность удара: `_Visual/AnimationPlayer` → `attack`.
  Подробности в [Enemy_Timing.md](Enemy_Timing.md).
- Здоровье: `_Components/HealthComponent` → Config.
- Дроп: `_Components/LootDropComponent` → Loot Entries.
  [Настройка предметов, количества и шанса](Loot_Setup.md).
- Урон и зона удара: `_Components/HitboxComponent` и его CollisionShape2D.
- Движение: EnemyMovementComponent или EnemyFlightComponent → Config.
- Обнаружение и подготовка удара: EnemyChaseComponent и EnemyAttackComponent → Config.

Перед запуском проверьте предупреждения EnemyAuthoringChecks. Для смены
кадров, длины атаки и перечисленных параметров редактировать GDScript не нужно.
