# Предметы

Целевая структура оружия и брони, цена продажи, результаты разлома и стартовые значения: [решение от 2026-09-17](../../docs/Item_Creation_Design.md). Новые значения пока зафиксированы в документации; текущие шаблоны ещё не полностью приведены к ним.

Каждый предмет — ресурс **ItemData** (`.tres`), который редактируется в Inspector.
Скрипт для отдельного меча или брони не нужен.

Принято новое правило доступа к предметам: требования по пассивным навыкам
(например, «Владение мечами 3» или «Ношение тяжёлой брони 5»), без требований
к силе, ловкости и другим статам. [Описание и статус миграции](../../docs/Actor_Stats.md#пассивные-навыки-и-требования-предметов).
Требования статов удалены. Поля и проверки навыков ещё не добавлены;
до их реализации предметы не ограничены уровнем характеристик или навыков. Неактивные коэффициенты масштабирования оружия от статов
подключать не планируется.

| Папка | Содержимое |
| --- | --- |
| weapons | Оружие |
| armor | Броня |
| offhand | Щиты и предметы второй руки |
| accessories | Кольца и украшения |
| consumables | Зелья, фляги и другие расходники |
| ammunition | Стрелы и болты |
| throwables | Метательные предметы |
| scrolls | Свитки |
| materials | Материалы |
| keys | Ключи |
| lore | Записки и сюжетные предметы |
| templates | Заготовки для создания новых предметов |

## Создать предмет

1. В панели FileSystem откройте `game/items/templates`.
2. Скопируйте подходящий `.tres` через **Duplicate** в контекстном меню,
   переименуйте копию и переместите в папку категории. Например,
   `Weapon.tres` → `weapons/IronSword.tres`.
3. Выберите копию. В **Identity → Id** задайте уникальный постоянный ключ,
   например `iron_sword`. В шаблонах Id специально пустой.
4. В **Presentation** заполните **Display Name**, **Description**, **Icon**.
   Перетащите свою PNG-текстуру в Icon. Шаблон содержит иконку-заглушку.
5. Настройте категорию, редкость, массу, цену и стопку. У нестопочного предмета
   Max Stack Size должен быть 1.
6. Раскройте **Profiles**. Нужные профили уже встроены в шаблон: у оружия есть
   урон и действия, у брони — слот и защита, у расходника — эффект.
7. Сохраните ресурс. Добавьте его в InventoryComponent → Config → Starting Items
   вместе с количеством в Starting Quantities либо в таблицу добычи.

Само сохранение файла не добавляет предмет в инвентарь. Для начального оружия
также укажите его Id в EquipmentComponent → Starting Main Hand Ids.

Можно начать с **New Resource → ItemData**, затем добавить нужные профили
вручную. Категория классифицирует предмет; она сама не создаёт профиль и не
определяет разрешённые слоты. Для брони слот задаётся в Equipment Profile →
Allowed Slots; для оружия — там же, а действия в Weapon Profile.

Копируйте файл шаблона, а не редактируйте сам шаблон. Его профили встроены в
`.tres`, поэтому копия файла получает собственные настройки. Если вручную
назначили общий внешний профиль нескольким предметам, используйте **Make Unique**
перед изменением только одного предмета.

Шаблоны описывают данные существующих механик, не добавляя новых: ключи,
материалы и записки пока не получают особого поведения автоматически.
Неактивные боевые параметры отмечены **Planned (inactive)**.

## Метательные предметы

В копии `templates/Throwable.tres` настройте **Profiles → Projectile Profile**:
**Texture** — текстура летящего предмета (исходное изображение направлено вправо),
а **Presentation → Icon** — отдельная иконка для инвентаря.
**Rotation Speed** задаёт вращение в градусах в секунду: `0` по умолчанию —
без кувыркания, с направлением вдоль траектории; `360` — один оборот в секунду
по часовой стрелке, `-360` — против часовой. Вращение начинается с угла броска
и не меняет траекторию, урон или время жизни снаряда.

**Status Effects** — список эффектов при попадании, по умолчанию пустой (нет DOT).
Добавьте ресурсы из `game/status`, например `poison.tres`, для отравленного ножа.
Урон тика, интервал и длительность задаются в самом StatusEffect; для отдельного
варианта сделайте ресурс уникальным. Можно назначить несколько эффектов.
Они накладываются только после удара, снявшего здоровье с выжившей цели;
полный блок и неуязвимость предотвращают наложение. Первый тик происходит
после Tick Interval и учитывает сопротивление цели — см. [DOT](../../docs/DOT.md).

## Отображение предмета на персонаже

Слот инвентаря и рука отображения настраиваются отдельно:

- **Equipment Profile → Allowed Slots** — куда предмет можно надеть.
- **Equipment Profile → Display Slot** — где он виден на риге: **Same As Equipment**
  (по умолчанию), **Main Hand**, **Off Hand**.
- **Presentation → Equipped Texture** — изображение для подмены текстуры
  соответствующего Sprite2D. **Icon** используется только в интерфейсе.

Например, у лука и арбалета Allowed Slots содержит Main Hand, а Display Slot —
Off Hand. Это уже настроено в их шаблонах и учебных предметах. Для учебного
арбалета ещё нужно назначить графику. Слот боеприпасов и логика стрельбы не меняются.

Спрайты MainHand/OffHand сохраняют свои привязки, повороты, Centered и Offset;
анимации работают с теми же костями и IK-целями. Изображения готовьте в нативном
размере под точку хвата. Если отдельному предмету нужны собственные смещения или
несколько частей, назначьте **Equipped Visual** — сцену с корнем Node2D и точкой
хвата в начале координат. При назначенных обоих полях приоритет у Equipped Texture.

Стрелы и болты не занимают визуальную руку: надетые боеприпасы активного комплекта
включают спрайт Arrows (колчан). После снятия или расходования последней единицы
он скрывается. Оба типа пока используют одно изображение колчана.
